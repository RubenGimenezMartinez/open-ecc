# Modelo Gratuito

Selecciona y configura un modelo gratuito de OpenCode para usar con ECC Simplificado.

## Uso

`/modelo-gratuito [nombre-modelo]`

## Modelos Gratuitos Disponibles

| Modelo | Ideal para |
|--------|------------|
| **Nemotron 3.5 Super VL** | Desarrollo general, coding (recomendado) |
| Beam | Tareas ligeras, pair programming |
| LongCat 2.5 Preview | Contextos largos, documentos extensos |
| Space Bunny | Razonamiento complejo |
| MiMo-V2.6-Flash | Respuestas rápidas, tareas simples |
| DeepSeek V4.1 Flash | Coding, razonamiento técnico |
| GLM-5.3-Flash | Tareas multilingües |
| Nemotron 3.5 Lightning | Velocidad, tareas repetitivas |
| Nemotron 3 Ultra | Tareas complejas, arquitectura |
| Big Pickle | Tareas especializadas |

## Pasos

1. Abre OpenCode
2. Ve a **Configuración → Seleccionar modelo**
3. Elige **Nemotron 3.5 Super VL** (u otro modelo gratuito)
4. Confirma que aparece la etiqueta "Gratis"

## Ejemplo

```bash
/modelo-gratuito Nemotron 3.5 Super VL
```

## Notas

- No se requiere API key ni tarjeta de crédito
- Los modelos gratuitos son proporcionados por OpenCode
- Puedes cambiar el modelo en cualquier momento desde la UI
- ECC Simplificado funciona con cualquier modelo gratuito
